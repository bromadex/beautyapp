## App content (Policy section)

**Privacy policy URL:** https://beautyapp-swart.vercel.app/privacy

**App access:** Some features need an account. Give the reviewers a test login
(create a client account and a pro account just for Google, and paste their
emails and passwords here). Guests can also browse without signing in.

**Ads:** No, the app doesn't contain ads. (Pros' product listings are part of
the service, not third-party ads.)

**Content rating questionnaire:** Category "Utility, Productivity, Communication
or other". Answer:
- Violence, sexuality, language, controlled substances, gambling: No.
- Users can interact or exchange content: **Yes** (chat between clients and
  pros, reviews, photos).
- Shares user location with other users: **No** (only city and area; no live location).
- Allows purchases of digital goods: **Yes** (pros buy plans, featured spots and ads).

**Target audience:** 18 and over only.

**News app:** No. **COVID-19 app:** No. **Government app:** No.
**Financial features:** None of the listed ones (the app doesn't hold money or
lend; clients pay pros directly).

**Account deletion:**
- Can users delete their account in the app? **Yes**: Account settings → Delete Account.
- Web link for deletion requests: https://beautyapp-swart.vercel.app/delete-account

## Data safety form

Does the app collect or share user data? **Yes.**
Is all data encrypted in transit? **Yes.**
Can users request that data is deleted? **Yes.**

For every type below: **Collected = Yes, Shared = No** (the companies that host
the app for us, such as Supabase, Google Firebase and Paynow, count as "service
providers", which Google doesn't treat as sharing). Processing is not ephemeral.

| Data type | Required or optional | Purposes |
|---|---|---|
| Location → Approximate location | Optional | App functionality |
| Location → Precise location | Optional | App functionality |
| Personal info → Name | Required | App functionality, Account management |
| Personal info → Email address | Required | App functionality, Account management |
| Personal info → User IDs | Required | App functionality, Account management |
| Personal info → Address | Optional | App functionality |
| Personal info → Phone number | Optional | App functionality, Account management |
| Personal info → Other info (gender of pros, ID photos for verification) | Optional | App functionality, Fraud prevention, security and compliance |
| Financial info → Purchase history | Optional | App functionality |
| Financial info → Other financial info (payment references, EcoCash numbers) | Optional | App functionality |
| Messages → Other in-app messages | Optional | App functionality |
| Photos and videos → Photos | Optional | App functionality |
| App activity → Other user-generated content (reviews, bookings) | Optional | App functionality |
| App info and performance → Crash logs | Required | Analytics |
| App info and performance → Diagnostics | Required | Analytics |
| Device or other IDs | Required | App functionality (notifications), Analytics (error reports) |

Not collected: health, contacts, calendar, audio, files, web browsing, emails,
SMS, installed apps.
